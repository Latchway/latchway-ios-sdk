# Latchway iOS SDK 1.1.0

Expanded Apple Foundation Models integration and the LatchwayChat iPhone example.

## Changes

- Guided `@Generable` and dynamic JSON Schema output, including nullable fields.
- Enabled tools, parallel tool calls, complete call/result history, and multi-turn sessions.
- Greedy and unseeded top-p/top-k translation, context options, reasoning, and metadata.
- Bounded streaming, terminal usage, refusal/cancellation handling, and safe tool dispatch.
- Optional iOS 27 CocoaPods `Latchway/FoundationModels` subspec.
- LatchwayChat with Firebase login/sign-up, real App Attest, Settings-selectable
  Foundation Models or Custom URLSession, and a live Open-Meteo weather tool.

## Install and compatibility

Use the `v1.1.0` Swift Package tag or CocoaPods `Latchway`, version `1.1.0`.
The core SDK remains iOS 15+. Foundation Models requires Xcode 27 / Swift 6.4
and OS 27; tvOS is unavailable. CocoaPods exposes the adapter in module
`Latchway`, while SwiftPM uses product/module `LatchwayFoundationModels`.

The expanded Responses route requires **Latchway server 1.0.2**. Contract 1.0.0
and wire protocol 2 remain unchanged. Existing transport integrations do not
need to adopt Foundation Models.

## Known limits

This is a remote model adapter, not Apple's on-device model. Seeded sampling
and image attachments are not supported. Top-k, reasoning effort, and schema
guides depend on the upstream model. Strict text-based input quotas reject
opaque encrypted reasoning and recursive/unresolved schemas. The example
explicitly requests non-reasoning mode for its hard total-token quota; it does
not disable enforcement. See the [complete integration guide](../../Documentation/FoundationModels.md).

## Verification

The full Swift package suite, 17 actual iOS 27 Foundation Models simulator
tests, and the optional CocoaPods subspec validation pass. A development
iPhone 16 Pro completed two cities with two live weather lookups, four
Responses requests, and 11,200 settled tokens. The original URLSession engine
also passed. Firebase Auth, App Attest, Secure Enclave, and DPoP were real.
This is not production Apple distribution or extension certification.

The example contains no Firebase client plist, credentials, signing assets,
or persistent chat. Add your own Firebase client configuration and update the
example's public gateway/app identifiers before using another deployment.
