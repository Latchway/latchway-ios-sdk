# Latchway iOS SDK 2.0.0

This major version makes provider-neutral supplied-identity shared apps and
accounts the only root integration. Native and React Native may configure in
either order and share the same native account. Application code owns identity
tokens; Firebase is not a required SDK dependency.

## Breaking changes

- Remove legacy root constructors, identity authorities, activation/transfer
  APIs, old Keychain adoption/migration callbacks and legacy storage inventories.
- Root storage uses the signed, explicitly configured private Keychain group.
  Old installation credentials are not adopted or migrated automatically;
  deny-only extension safety markers remain checked.
- Delegated extensions require an explicit current-account handoff and their
  own approved component group. Direct iOS extension attestation stays
  unavailable, with the compile-time and runtime denial guards retained.
- Shared-account root clients use contract 1.1.0 / wire protocol 3. Published
  protocol compatibility constants and fail-closed internal guards are retained.
  Update embedded
  React Native to its paired 2.0.0 integration and rebuild the native application.

App-level `signOut()` remains available from 1.3.0. It retires the shared account,
cancels pending identity work, and retries interrupted cleanup without requiring
application code to inspect account handles or journals. Supplied-identity
sign-in, expiry recovery, account isolation and current component retirement
remain supported.

## Development attestation

Server 1.1.3 accepts Apple `development`, `production`, or
`any` as server policy. `any` is not an Apple entitlement. The native provider
needs no new environment flag; regression coverage verifies one-key recovery
when Apple rejects a persisted key and preserves valid keys after an
unacknowledged assertion. TestFlight uses Apple's production environment.

Fixture and build verification is not new physical App Attest, TestFlight or
extension-process proof. See the development-attestation and physical-device
runbooks for the remaining live checks. Existing 1.x tags remain unchanged.
